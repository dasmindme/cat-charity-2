# cat-charity-2 (QRKot)

Благотворительный сервис фонда QRKot: в фонде создаются целевые проекты по сбору средств, а пользователи отправляют пожертвования. Пожертвования автоматически инвестируются в самые ранние открытые проекты. Если пожертвование превышает потребность проекта — остаток переносится в следующий открытый проект.

## Стек
- Python 3.12+
- FastAPI
- SQLAlchemy (async) + aiosqlite
- Alembic (миграции)
- fastapi-users (регистрация/аутентификация)

## Функциональность

### Проекты (`/charity_project/`)
- Просмотр списка проектов доступен всем пользователям.
- Создание/редактирование/удаление доступно только суперпользователю.
- Закрытый проект нельзя редактировать.
- Нельзя установить `full_amount` меньше уже инвестированной суммы.
- Нельзя удалить проект, если в него были инвестированы средства.

### Пожертвования (`/donation/`)
- Зарегистрированный пользователь может создать пожертвование.
- Средства автоматически инвестируются в открытые проекты (по принципу «самый старый открытый проект первым»).
- Пользователь может получить список своих пожертвований: `/donation/my`.
- Суперпользователь может получить список всех пожертвований: `GET /donation/`.

## Инвестирование
Инвестирование запускается:
- при создании проекта — в проект вкладываются свободные пожертвования;
- при создании пожертвования — средства распределяются по открытым проектам.

Коммит выполняется один раз в конце операции (создание + инвестирование в одной транзакции).

## Установка и запуск (Windows)

1) Клонировать репозиторий и перейти в папку проекта.

2) Создать и активировать виртуальное окружение:
```powershell
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1

3) Установить зависимости:
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

4) Применить миграции:
python -m alembic upgrade head

5) Запустить приложение:
python -m uvicorn app.main:app --reload

Swagger-документация будет доступна по адресу:

http://127.0.0.1:8000/docs
